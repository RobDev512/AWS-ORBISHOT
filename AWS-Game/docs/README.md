# Documentación de AWS ORBISHOT

Esta carpeta concentra la documentación histórica y de release del juego.

- `CHANGELOG.md` — cambios por versión.
- `RELEASE_NOTES.md` — resumen funcional de cada release.
- `ROADMAP.md` — dirección y versiones futuras.
- `specs/` — archivo histórico de especificaciones desarrolladas originalmente con Kiro.

El `README.md` principal permanece en la raíz de `AWS-Game/` para que GitHub lo muestre automáticamente.
